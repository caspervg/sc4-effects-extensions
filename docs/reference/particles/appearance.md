# Appearance curves

Status: `Confirmed`

These particle subcommands define the visual curves and basic lifetime data.

## Recovered commands

- `zoom`
- `color`
- `color255`
- `colour`
- `colour255`
- `alpha`
- `alpha255`
- `size`
- `aspect`
- `rotate`
- `stretch`
- `life`

## Notes

- `color` samples are grouped color arguments
- `alpha`, `size`, `aspect`, and `rotate` support variation values
- `life` supports a base value plus optional symmetric variation
- `life` also supports `-preroll`
