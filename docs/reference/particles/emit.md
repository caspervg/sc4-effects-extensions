# `emit`

Status: `Confirmed`

`emit` controls emission timing and initial motion.

## Syntax

```fx
emit [options...]
```

## Timing and count options

- `-rate <float...>`
- `-inject <float>`
- `-loop <float> [uint]`
- `-single [float]`
- `-sustain`
- `-scale`
- `-areaScale`
- `-volumeScale`
- `-delay <a> [b]`
- `-trigger <a> [b]`
- `-retrigger <a> [b]`

## Initial motion options

- `-velocity <vec3> [speed] [vary]`
- `-speed <float> [vary]`
- `-dir <vec3> [float | vec3]`
- `-vel <vec3>`
- `-base`
