# `terrainRepel`

Status: `Confirmed`

Dedicated terrain-repulsion particle subcommand.

## Syntax

```fx
terrainRepel <a> <b> [-scout <c>] [-vertical <d>] [-killHeight <e>]
```

## Recovered options

- required first two floats
- `-scout <float>`
- `-vertical <float>`
- `-killHeight <float>`

## Notes

- valid only inside `particles`
- closely related to `force -terrainRepel`
