# Particle overview

`particles` is the richest recovered authoring family so far.

A particle definition combines:

- appearance curves
- spawn domain
- emission rate or injection
- initial direction / speed
- persistent forces
- terrain and collision interaction
- texture or model rendering
- optional effect chaining
