# `shake`

Status: `Partial`

`shake` defines a named reusable shake description consumed by `shakeEffect`.

## Syntax

```fx
shake name [: baseName]
    length ...
    amplitude ...
    frequency ...
    shakeAspect ...
    table ...
end
```

## Recovered nested commands

- `length`
- `amplitude`
- `frequency`
- `shakeAspect`
- `table`
